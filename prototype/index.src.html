why mudlet

What keeps people playing

Works anywhere

Windows, macOS and Linux — even Chromebooks and Raspberry Pi. Scripts written on one machine run on the next, and profiles sync however you like.

Fast & lightweight

Performance defined Mudlet from the start. A custom text display and Lua-powered scripting handle the biggest raids without dropping a frame.

100% modifiable

Every part of the interface is designed to be modded — from the space inside the window to the look and feel of the client itself.

A real mapper

2D and 3D mapping with built-in pathfinding. Walk once and Mudlet remembers — then draw custom exits or drop a background image over an area.

Free and open source

Free to download, modify and extend, under the GPL. Build on a powerful foundation and join us in making MUDing awesome.

Approachable

A friendly Discord of over 5,000 players, and a scripting API carefully designed to be simple and intuitive before it is powerful.

What is Mudlet?

A platform for playing and enhancing text games. Mudlet gives players and creators a toolkit and broad protocol support to tailor an immersive experience.

Creators use it to add visual flair or build features into their games. Players use it to script and automate their play, or to visualise game data their own way.

It has even been used outside MUDs entirely — automating 3D games that expose in-game chat over Telnet.

What are MUDs?

A multiplayer real-time virtual world, usually text-based, combining role-playing, hack and slash, player versus player, interactive fiction and online chat. Players interact by typing commands that resemble natural language.Wikipedia

The kind of game you fall in love with for its stories, its raids, its politics — or just for the people.

Other ways to install

ChromeOS

Mudlet runs on ChromeOS through Linux (Crostini). The wiki has step-by-step instructions.

Ubuntu & Debian

Use the AppImage above. The Mudlet in Debian’s repositories is out of date — if you maintain it, we’d love your help.

Portable

The Linux build is portable. Extract the launcher somewhere permanent, then run Mudlet from there.

Build it yourself

The wiki carries build instructions for each OS.

git clone https://github.com/Mudlet/Mudlet

Older versions

Every previous installer is still available, back to the early releases. Browse the archive.

Want to test new developments?

The Public Test Build carries everything that has landed since 4.22.0, on all three platforms. Tell us how it goes.

Playing with a screen reader?

We keep detailed setup instructions for screen-reader software and Mudlet’s other accessibility options.

Windows builds are code-signed free of charge by SignPath.io, with a certificate from the SignPath Foundation. Mudlet does not transfer any information to other networked systems unless you ask it to.

Release 4.22.0

4.22 — mapping, made friendlier

VP Vadim Peretokin· 6 July 2026· 3 min read

Mudlet 4.22 is out — a mapper-focused release. Two things that until now needed a script can be done from the interface, and Windows builds arrive signed.

In this post
Manage your map areas visually Lock stub exits without scripting Signed Windows installers Everything in 4.22.0

Manage your map areas visually

You can now create, rename and delete map areas right from the mapper, with the new Configure Areas dialog. No scripting needed — a long-requested feature, finally here.

Lock stub exits without scripting

The Set Exits dialog’s “No route” checkbox now works for stub exits, bringing the interface in line with what the Lua API could already do. Two related fixes come with it:

  • saving a room no longer clears locks that were set from a script;
  • map audits keep those locks instead of dropping them.

Signed Windows installers

Windows builds are now code-signed through SignPath.io, with a certificate from the SignPath Foundation — so the installer no longer arrives from an “unknown publisher”.

Upgrading is free and leaves your profiles, packages and maps exactly where they are.
